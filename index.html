就绪
• 关闭（串行）：先答模型A，再答模型B。速度稍慢，但对电脑性能负担小。
• 开启（并行）：两个模型同时回答。速度翻倍，但对显存和算力要求极高，低配电脑可能会卡死。
让 AI 记住你的偏好和事实。每次对话会自动检索最相关的记忆并注入上下文。
图片最长边上限 像素（越小越省 token 与存储）
• 图片发送前会在本地压缩并转成 JPEG，不会上传到除了你选定平台以外的任何服务。
• 需要选择支持视觉的模型（本地如 llama3.2-vision / llava / qwen2-vl，云端如 gpt-4o / qwen-vl-max）。
• 浏览器本地存储约 5MB，图片会占用其中一部分，建议及时清理不需要的对话。
让模型能主动调用本地只读工具（读取当前时间、精确计算、检索知识库、列出 Skill、读取会话状态）。 全部在浏览器本地执行，无副作用。你也可以右键顶栏的「🔧 工具」按钮查看工具清单。
最大调用轮次 轮（防止模型陷入无限调用）
⚠️ Ollama 的部分模型对 tool calling 支持参差不齐。若开启后出现报错或回答异常，关闭此开关即可恢复原状。
