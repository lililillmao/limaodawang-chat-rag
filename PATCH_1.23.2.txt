狸猫AI工具盒 · 补丁更新说明
补丁版本：v1.23.2
发布目的：修复 5 个影响使用体验的 bug
================================================================

本次补丁修复了 1.23.1 发布后发现的 5 个 bug，涉及云平台接入、
Skill 热更新、工具调用、记忆并发、图片存储等模块。全部为兼容性
修复，不改变任何既有数据结构，用户升级后无需迁移数据。

----------------------------------------------------------------
【P0 严重】修复云平台 /v1 前缀缺失导致 OpenAI 兼容平台不可用
----------------------------------------------------------------

问题：fetchModels 和 testProviderConnection 硬编码请求
      baseUrl + "/models"，当用户填的是 https://api.deepseek.com
      或 https://api.openai.com 时（未带 /v1），请求会打到
      https://api.deepseek.com/models → 404。

影响：云平台的模型列表拉不到，顶栏下拉框空白；"测试连接"按钮
      永远显示失败。除 Ollama 外所有外部平台几乎不可用。

修复：新增 resolveOpenAIModelsEndpoint()，与已有的
      resolveOpenAIEndpoint() 保持一致的推断逻辑：
        · baseUrl 已写全 /models → 直接用
        · baseUrl 是 .../v1   → 补 /models
        · baseUrl 是 .../v1/x → 归一化
        · 其它情况           → 补 /v1/models
      fetchModels 和 testProviderConnection 都改用它。

涉及文件：js/api.js

验证方式：设置 → 平台管理 → 新增 DeepSeek 平台
          地址填 https://api.deepseek.com（不加 /v1）
          点"测试连接"应显示 ✅ 连接成功

----------------------------------------------------------------
【P1】修复 Skill 内容变化后前端缓存不刷新
----------------------------------------------------------------

问题：同一页面会话内改 SKILL.md，watchdog 会重建向量库，但前端
      skillMetaCache 里还缓存着旧的 prompt。setActiveSkills 判断
      promptMissing = false，不会重新拉取。用户以为"改了没生效"。

修复：pollBuildStatus 检测到 build_status 从 running → completed
      且触发源是 watchdog/startup 时：
        1. 清空所有 Skill 的 prompt 与 emoji 缓存
        2. 若有已加载的 Skill，立即重新拉取一次
      状态栏会显示 "✅ Skill 内容已更新"。

涉及文件：js/main.js（新增 invalidateSkillCache 与
          refreshActiveSkillsFromServer）

验证方式：加载一个 Skill → 在文件系统里改它的 SKILL.md
          → 等 2-3 秒 → 底部状态栏应提示"Skill 内容已更新"

----------------------------------------------------------------
【P2】修复嵌套 JSON 工具调用识别失败
----------------------------------------------------------------

问题：extractTextToolCalls 用单层正则
      /"arguments"\s*:\s*(\{[^{}]*\})/ 只能匹配一层花括号。
      当模型（典型如 qwen2.5:7b）把工具调用当文本输出、且参数
      含嵌套对象时（如 {"query": "cat", "opts": {"top_k": 3}}），
      整段匹配失败，工具不会执行。

修复：改用"括号平衡扫描"（_scanJsonValue）从 "arguments": 之后
      手工配对 { } [ ]，同时正确处理字符串中的转义引号。
      兼容对象、数组、字符串三种参数形态。

涉及文件：js/features/chat.js

----------------------------------------------------------------
【P2】修复对比模式下记忆提取重复写入
----------------------------------------------------------------

问题：对比模式两个 runStream 几乎同时完成，并行调用
      extractMemoryFromConversation。两边都读到旧的 memories
      快照，some() 去重都为 false，同一条记忆被 addMemory 两遍。

修复：加模块级布尔锁 _extractingMemory：
        · 进入前检查，若已有提取在进行则直接返回
        · try/finally 保证无论如何都释放锁
        · 写入前额外 fetchMemories 一次，基于最新快照去重

涉及文件：js/features/chat.js

----------------------------------------------------------------
【P2】收紧图片存储阈值，避免两轮对话打爆 localStorage
----------------------------------------------------------------

问题：单张图片上限 400KB × 6 张 = 2.4MB，加上其他数据，
      两轮带满图的对话就会撑爆浏览器 localStorage 的 5MB 配额。
      （IMG_MAX_STORE_BYTES 是 dataURL 编码后长度，base64 通常
      比原图大 33%，实际可用空间更小。）

修复：
  · 单张上限 400KB → 200KB
  · 单轮张数 6 → 4
  · 压缩质量档位 [0.85,0.75,0.65,0.55,0.45]
    扩为 [0.85,0.75,0.65,0.55,0.45,0.35]
  · 默认最长边 1568px → 1024px

  1024px 足够大多数视觉模型识别内容，体积小一半以上。
  用户如需更高清，可在「设置 → 视觉输入」手动调回 1568。

涉及文件：js/ui/input.js、js/config.js

----------------------------------------------------------------
【P3】工具按钮提示文案修正
----------------------------------------------------------------

问题：开启工具的提示写的是"点击可按 Shift 查看工具清单"，
      实际是右键触发。

修复：文案改为"右键按钮可查看工具清单"。

涉及文件：js/main.js

----------------------------------------------------------------
【兼容性说明】
----------------------------------------------------------------

· cfg（chat_cfg）结构未变，仅默认值调整：imageMaxEdge 从 1568
  降到 1024。已保存的用户配置不受影响（loadLocal 时保留原值）。
· sessions / messages / presets / memory.json / chroma_db /
  file_hashes.json 完全未改动。
· 备份文件格式仍是 {version, savedAt, cfg, sessions, presets,
  drafts}，与 1.23.0 / 1.23.1 双向兼容。
· 无需清空任何缓存、无需重建向量库、无需重新导入历史对话。

----------------------------------------------------------------
【升级方式】
----------------------------------------------------------------

直接覆盖以下 5 个文件即可：
  js/api.js
  js/main.js
  js/features/chat.js
  js/ui/input.js
  js/config.js

然后 Ctrl+F5 强制刷新浏览器。

【本次未处理，留待后续】
----------------------------------------------------------------

· safety_fallback_path 路径错误时后端缺少显式提示，会静默降级
  到硬编码兜底文本。用户无法察觉自己配置的兜底文档没用上。
  （建议：后端启动时检查路径是否存在，不存在则打印警告）

· 工具结果消息（role: "tool"，hidden: true）在会话中长期残留，
  长会话可能累积大量无意义的历史。多轮工具调用需要保留历史
  供模型回灌，但跨轮/跨会话的旧工具结果可以清理。
  （建议：加 pruneToolMessages() 在切换会话或页面加载时执行）

· accumulateToolCalls 的 name 拼接算法假设分片边界不重叠，
  极端情况下可能拼出错误名字。按 OpenAI 规范几乎不会触发，
  但代码可以简化为直接累加。
